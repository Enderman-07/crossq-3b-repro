CrossQ-3B
中期报告

面向策略更新路径的三批联合前向与归一化统计共享
课题类型：顶会论文复现与微创新
研究方向：连续控制与深度强化学习
复现基线：CrossQ（ICLR 2024）
实验环境：Ant-v4、Hopper-v4、Walker2d-v4
小组成员：梅振宇、金宇辉、沈乐乐、容子棋
报告日期：2026 年 11 月 9 日

摘要

本课题研究 CrossQ 评论家在策略更新时的归一化统计路径。标准 CrossQ 在评论家更新中把当前转移批与自举批拼成 2N 批共享当步 BatchNorm 统计量；策略损失所需的当前状态策略动作批通常另行前向，因而没有直接参与该次批统计估计。本研究据此提出可检验假设：在策略更新步把三类输入拼成 3N 批，可能改变策略梯度所依赖的归一化上下文，但效果不应预设为正向。

截至本报告，已完成三种 MuJoCo 环境、五个配对随机种子、六种方法、每个 run 一百万交互步的主比较，共 90 个 run。Original 3B（无 EMA）在 Ant 的 Final、AUC 和 held-out 均值高于 CrossQ，在 Hopper 呈现指标分化，在 Walker2d 三项均低于 CrossQ；因此，单纯加入第三批没有显示跨环境一致收益。EMA、分阶段启用和双目标 TDEMA 的表现也依赖环境与评价指标。现阶段结论是：第三批统计共享值得研究，但不能据当前结果声称其普遍优于 CrossQ；主要贡献应定位为策略更新路径的受控比较与机制边界分析。

中期判断：六方法的共同 1M 协议比较已完成。报告以 AUC、最后阶段均值和独立 held-out 为主要证据；“Best”仅作探索性描述，不作为泛化性能或方法优劣的主判据。

一、研究问题与假设

1.1 问题背景

REDQ 通过较大的评论家集成与较高更新—数据比提升样本效率，DroQ 使用 Dropout 和归一化控制集成规模带来的成本。CrossQ 的关键设计是在 UTD=1 的设置下取消目标评论家网络、保留双 Q 评论家，并在当前转移与自举目标输入之间联合前向，以共享归一化统计量。此处“取消目标网络”不等于取消双评论家。

策略更新还会查询 Q(s, π(s))。该策略动作分布并非完全未被评论家统计量见过：自举批中已经含有 π(s′)。更精确的研究问题是，当前状态上的策略动作批 (s, π(s)) 是否应直接参与策略更新当步的归一化统计估计，以及这种统计上下文变化会如何影响策略梯度和学习表现。

1.2 可证伪假设

  1. 性能假设：在同一环境交互预算和评估协议下，3N 联合前向可能改善 AUC 或独立 held-out 回报；若只在个别环境有效，应报告环境依赖而非总体胜出。
  2. 机制假设：若收益来自共享统计量而非减少调用次数，分组统计的等量批处理对照应不能复现该收益；该机制仍需单独消融确认。
  3. 计算假设：第三批提高演员更新步的批量样本数，不应仅凭“调用次数减少”推断 FLOPs、墙钟或显存改善，必须读取同协议运行数据验证。

二、方法与实现

2.1 CrossQ 更新目标

对回放样本 (s,a,r,s′,d)，策略分别在 s′ 和 s 上采样动作 a′ 与 aπ。TD 目标与两评论家损失为：

y = r + γ(1−d) · sg[min(Q₁(s′,a′), Q₂(s′,a′)) − α log π(a′|s′)]

LQ = Σj=1,2 E[(Qj(s,a) − y)²]

策略损失为 Lπ = E[α log π(aπ|s) − minj Qj(s,aπ)]。策略反向传播需要通过 Q 对动作求导，但不应将策略损失梯度累积到评论家参数。第三批联合前向会使 BN 输出依赖同批样本，因此它并非与原实现代数等价的单纯加速，而是统计量处理方式的有意改变。

2.2 3B 更新路径

非策略更新步按 CrossQ 使用 2N 批；每隔三个评论家更新的一次策略更新步，将 B=(s,a)、T=(s′,a′)、P=(s,π(s)) 拼为 3N，一次评论家前向产生各批输出。演员损失只读取 P 对应的输出，评论家损失只使用 B 与 T。策略和评论家损失都依据同一份更新前评论家参数快照计算，再按既定顺序更新，从而避免把评论家先更新后再评估策略的顺序差异混入方法比较。

Original 3B 的 EMA 变体仅对评估/部署用演员参数及浮点 BatchRenorm 统计量做指数滑动平均；在线采样和训练仍使用在线演员。主 EMA 配置在 100k 更新后启用，半衰期为 25k 更新。50k staged 条件把 3B 的起点延至 50k；TDEMA-50K 则在 50k 后同时启用双熵校正目标与 EMA 演员。

五、结果解读

5.1 Original 3B（无 EMA）：有明显任务依赖性

Ant 上 Final、AUC、Held-out 分别为 CrossQ 的 107.7%、118.0%、105.2%，三个指标的配对胜率均为 5/5。Hopper 上 Final 和 Held-out 分别为 110.9% 与 120.6%，但 AUC 为 96.5%；对应配对胜率依次为 3/5、2/5、3/5。Walker2d 三项分别为 92.9%、93.8%、89.8%，配对胜率均为 1/5。该结果是第三批策略输入影响性能的直接证据，同时也明确否定“3B 在所有环境普遍更好”的简单结论。

5.2 EMA 与 3B 的作用不能混为一谈

CrossQ + EMA 相对 CrossQ 的 AUC 均值在 Ant 近于持平（100.7%），在 Hopper 和 Walker2d 分别为 120.3% 和 105.4%，但均值变化在任务间不均匀。匹配 EMA 的 Original 3B + EMA 相对 CrossQ + EMA，在 AUC / Held-out 上 Ant 变化为 +18.0% / +6.1%，Hopper 为 −4.7% / +7.1%，Walker2d 为 −7.2% / −8.2%。因此，EMA 与三批统计共享具有不同作用路径，不应把 EMA 变体的优势归因于 3B 本身。

5.3 分阶段与双目标方法

50k staged Original 3B + EMA 在 Walker2d 的 AUC 和 Held-out 分别达到 106.8% 与 100.9%，但在 Ant 和 Hopper 的指标组合并未全面超过对应 CrossQ 基线。TDEMA-50K 在 Hopper 的 Final / Held-out 高于 CrossQ，在 Walker2d 的 AUC / Held-out 略高；Ant 的 AUC 为 99.9%，Held-out 为 96.9%，与 100% 基线近似持平或略低。早期五种子 300k 验证中 TDEMA-50K 曾在三环境的 AUC 和 held-out 均超过配对 CrossQ；扩展到 1M 后 Ant 的优势未保持，说明结论受训练时域与环境影响，不能把 300k 筛选结果外推为 1M 普遍优势。

关于 Best：Best 是从每个 run 的 100 次周期评估中挑出的最大值，含有明显的多重选择偏差，且被选中的 checkpoint 未再通过独立 held-out seeds 复评。因此它仅用于描述训练期间曾达到的峰值，不代表最终策略或泛化性能；主要判断依据应为 AUC、最后阶段评估和 held-out。

六、有效性边界与风险

  • 样本量：每个主条件 5 个配对种子，足以呈现趋势和配对胜率，但不宜把百分比变化解释为高精度总体效应。后续应补充 bootstrap 区间或更多种子。
  • 任务范围：当前只覆盖三项 MuJoCo 任务；结论不自动推广到其他连续控制基准、视觉任务或不同网络规模。
  • Best 选择：最大周期评估值经多次挑选，存在乐观偏差，不能作为主指标。
  • 机制归因：3N 同时改变批统计构成、单次张量大小和调用结构。需以分组统计对照区分共享统计量效应与纯工程批处理效应。
  • 计算开销：演员更新时实际处理约 3N 样本，理论计算量不因前向调用减少而自动下降。墙钟、吞吐率、峰值显存须从统一计时口径的日志单独汇总。
  • 版本可复现性：最终归档需补齐环境锁定文件、软件与驱动版本、运行命令、随机种子清单及评估配置。

第四阶段：复现归档锁定 Python、PyTorch、CUDA、Gymnasium、MuJoCo 版本，保存配置、日志、检查点与评估种子。可复现实验包与运行说明

八、阶段性结论

  1. CrossQ 复现及六方法的 1M 配对主比较已完成，覆盖 3 个环境、5 个种子，共 90 个运行，Original 3B 无 EMA 的新增矩阵 15/15 完成且未数值发散。
  2. Original 3B 的效果具有环境依赖性：Ant 指标改善，Hopper 指标分化，Walker2d 指标回退。当前证据不支持把 3B 宣称为跨任务通用改进。
  3. EMA、延迟启用 3B 与 TDEMA 的结果也因环境及训练时域而异；应分别报告，不将不同机制的收益混合归因。
  4. 后续工作的重点是统计共享机制消融、配对不确定性估计和计算成本实测。若受控消融不能证明统一性能收益，应将课题贡献界定为规范的实现、机制分析和适用边界，而非强行提出正向结论。
